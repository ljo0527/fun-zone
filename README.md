# fun-zone

만들면서 노는 작은 프로젝트들의 모음 페이지입니다. 첫 화면(`index.html`)에 프로젝트 카드가 놓이고, 카드를 누르면 각 프로젝트로 이동합니다.

- 주소: https://ljo0527.github.io/fun-zone/ (GitHub Pages, `main` 브랜치 루트에서 배포. 워크플로 없음)
- 지금 있는 프로젝트: [일확천금](https://ljo0527.github.io/lotto-lab/) (로또·연금복권 통계 실험실. 저장소는 `lotto-lab` 이며 옮기지 않고 링크로만 연결)
- 오락·실험용입니다. 결제, 광고, 당첨·수익 보장은 없습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 첫 화면. `projects.json` 을 읽어 카드를 그립니다. 읽지 못하면 안에 든 목록으로 그립니다. 마지막에 "추가 예정" 칸이 항상 붙습니다 |
| `projects.json` | 카드 데이터 |
| `CLAUDE.md` | 이 저장소의 작업 규칙 |
| `.nojekyll` | Pages 의 Jekyll 처리를 끕니다 |

## 프로젝트 추가 절차

1. 이름을 정합니다. 폴더·id 는 영문 소문자와 하이픈입니다. 표시 이름은 한글이어도 됩니다.
2. 두 가지 중 하나를 고릅니다.
   - 다른 저장소의 사이트로 연결만 한다: 폴더를 만들지 않습니다. `url` 에 그 주소를 씁니다.
   - 이 저장소 안에 만든다: `<id>/index.html` 로 정적 파일만 둡니다. `url` 은 `./<id>/` 처럼 상대 주소로 쓰면 됩니다.
3. `projects.json` 의 `projects` 에 카드 하나를 더하고, `index.html` 안의 `FALLBACK` 에도 같은 내용을 넣습니다.
4. 브라우저로 열어 모바일 폭(약 375px)에서 가로 스크롤이 없는지 봅니다.
5. 푸시 전에 점검을 돌립니다(개인 정보, 파일 크기). 푸시는 사람이 합니다.

카드 필드: `id`, `title`, `desc`, `url`(https 주소나 같은 출처의 상대 주소만 허용), `tags`(문자열 배열), `status`(`운영 중` 이면 초록 배지).

## 로컬에서 보기

```powershell
python -m http.server 8766
```

주소창에 `http://localhost:8766/` 를 엽니다. 파일을 더블클릭해 열어도 보이지만, 그때는 `projects.json` 을 읽지 못해 내장 목록으로 표시됩니다.
